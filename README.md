# iComputers E-Commerce Website

## Overview
iComputers is a modern e-commerce web application designed for purchasing computer hardware, accessories, and technology products online. The platform provides a user-friendly shopping experience with product browsing, search functionality, shopping cart management, secure user authentication, and order processing features.

## Features

### Customer Features
- User Registration and Login
- Browse Products by Categories
- Product Search and Filtering
- Product Details View
- Shopping Cart Management
- Secure Checkout Process
- Order Tracking
- User Profile Management
- Product Reviews and Ratings

### Admin Features
- Dashboard Overview
- Product Management (Add, Edit, Delete)
- Category Management
- Order Management
- User Management
- Inventory Management
- Review Moderation
- Sales Monitoring
